LINE 電子名片產生器

填表單 → 下載 → 拖曳上線。不用寫任何程式碼。

右邊顯示的是範例。表單已經先填好一組假資料，讓你看得到成品長什麼樣—— 直接把每一格改成你自己的就好，預覽會即時跟著變。

1 · 基本資料

會顯示在名片圖和網站最上方。

2 · 形象照

會自動裁成直幅 3:4 並壓縮。建議用正面、背景單純的照片。

點這裡選照片 或把檔案拖進來 · JPG / PNG

框式：米白底 + 照片放在圓角框裡。適合去背照、大頭照。
滿版 · 低調：文字不搶戲，讓照片主導。適合本身已經有設計感的照片，例如雜誌風、情境照。
滿版 · 強烈：職稱做成主色標籤壓在姓名上方，層級分明。適合一般半身照、證件照。
兩種滿版都會自動改用直式比例 2:3。

滿版提醒：照片下半部會被漸層蓋住放文字，請挑人物位於畫面偏上的照片。 人站太低的話臉會被文字壓到——先拉「裁切位置」滑桿往左試試，還是不行就換一張。
裁切位置 30%

往左＝保留較多頭頂，往右＝保留較多肩膀。調到臉在畫面中上方最好看。

3 · 自我介紹

空一行就會分段。建議 100～200 字。

4 · 經歷 選填

過去的職位、學歷、合作過的對象，或你提供的服務。留空就不會出現這個區塊。

例如：經歷、過去經驗、業務發展、服務項目、合作客戶。

想加小字說明的話，用全形的「｜」分隔：主要內容｜右側小字。不加也可以。

5 · 連結

留空的不會出現。

6 · 聯絡方式

兩種都會寫進「存聯絡人」檔案，差別只在網頁上看不看得到。

網站是公開的。選「直接顯示」等於把號碼貼在網路上，垃圾訊息會變多。選「不顯示」的話，對方要按「存聯絡人」才拿得到。

7 · LIFF ID

先留空沒關係。網站上線後再回來填，重新下載一次即可。

填了之後，在 LINE 裡開啟時會多出「分享名片給好友」按鈕。沒填的話網站其他功能完全正常。

第一步 · 讓網站上線

下載的 ZIP 解壓縮後，要把裡面的檔案放到網路上，才會有網址可以給別人。兩種方式選一種就好。

Netlify DropGitHub Pages
難度最簡單，拖曳即可步驟較多，但都是點選
要帳號要（可用 Google 登入）要（GitHub 帳號）
網址隨機名稱，可自訂含你的帳號名稱
改內容整包重拖一次上傳同名檔覆蓋
費用免費免費
方式 A · Netlify Drop最快
  1. 先註冊並登入 Netlify：用電腦的一般瀏覽器開 app.netlify.com， 按 Sign up，用 Google 或 GitHub 一鍵登入。
    這步一定要在拖檔案之前做。沒登入就拖的話， 站台會被擋在登入牆後面，別人打開會看到錯誤，連你自己在 LINE 裡也開不了。
  2. 登入狀態下開 app.netlify.com/drop， 把整個資料夾拖進畫面中央的虛線框。
  3. 幾秒後出現網址，像 https://melodic-tapioca-1a2b3c.netlify.app。
  4. （建議）進站台 → Site configuration → Change site name，改成好記的名字。
  5. 用手機打開確認。把網址記下來，後面會一直用到。
怎麼確認真的公開了：用手機的無痕視窗打開那個網址。 跳出 Netlify 登入畫面就是沒登入就拖了，登入後重拖一次即可。
方式 B · GitHub Pages長期穩定
  1. 沒有帳號的話先註冊：github.com/signup（免費）。
  2. 開 github.com/new 建立新的 repository：
    ・Repository name：用英文小寫，不要空格，例如 mycard
    ・選 Public　必須公開，免費版的 Pages 只支援公開 repo
    ・不要勾 Add a README file
    ・按 Create repository
  3. 新頁面中間有一行小字 uploading an existing file，點它。
  4. 把解壓縮後資料夾裡的檔案全部拖進去 （index.html、card.png、card-flex.jpg）。
    這裡拖的是「檔案」，不是資料夾。 拖資料夾的話網址會多一層，變成 .../mycard/資料夾名/
  5. 往下捲，按綠色的 Commit changes。
  6. repo 上方 Settings → 左欄 Pages：
    ・Source 選 Deploy from a branch
    ・Branch 選 main，資料夾選 / (root)
    ・按 Save
  7. 等 1～2 分鐘，重新整理 Settings → Pages，上方會出現 Your site is live at 和你的網址：
    https://你的帳號.github.io/mycard/
  8. 用手機打開確認。把網址記下來。
往後要改內容：回本頁改好、重新下載，然後 repo → Add file → Upload files → 拖同名檔案進去 → Commit。同名會自動覆蓋，不用先刪。 改完一樣要等 1～2 分鐘才會生效。

圖片沒出現？通常是只傳了 index.html、忘了傳圖。 直接用瀏覽器打開圖片網址（例如 https://你的帳號.github.io/mycard/card-flex.jpg）， 看到 404 就是沒傳成功。

第二步 · 把名片傳出去

網站上線後就能用了。三種方式選一種，不需要 LINE 官方帳號。

要準備對方看到
A 貼網址不用準備小張連結預覽卡
B QR code不用準備掃完直接開網站
C 分享按鈕一組 LINE Login channel大張名片圖
方式 C · 分享按鈕推薦

裝好之後，你的名片頁底部會多一顆「分享名片給好友」。 任何打開你名片的人都能按，直接把名片轉傳給他自己的好友——名片會自己長腳。

  1. 開 developers.line.biz/console， 用你的 LINE 帳號登入。
  2. 第一次進來要先建一個 Provider（服務提供者），名稱填你的名字或品牌名。 已經有的話直接點進去。
  3. 按 Create a new channel → 選 LINE Login。
    一定要選 LINE Login。LIFF 不能建在 Messaging API channel 上。
    這不會產生官方帳號，兩者是不同的東西。
  4. 填寫：Channel name 用你的名字 + 電子名片（會顯示在授權畫面上）、 App types 勾 Web app、Email 填你的信箱 → 建立。
  5. 進入剛建好的 channel → 上排 LIFF 頁籤 → Add。
  6. 填寫：
    ・LIFF app name：電子名片
    ・Size：Full
    ・Endpoint URL：第一步拿到的網址（結尾斜線要留）
    ・Scopes：勾 profile 和 chat_message.write
    chat_message.write 沒勾，分享按鈕按下去會失敗。
    ・Bot link feature：Off
  7. 建好後在 LIFF 頁籤點 shareTargetPicker，跳出的 「Agreement Regarding Use of Information」按同意。
  8. 複製 LIFF ID（像 2011843906-bu8IybC3）。
  9. 回到本頁第 7 格貼上 → 重新下載 → 重新上傳覆蓋。
  10. 用手機的 LINE 開 https://liff.line.me/你的LIFF ID， 第一次跳授權畫面按允許，分享按鈕就會出現。
分享按鈕只在 LINE 內建瀏覽器才看得到。用電腦或手機的一般瀏覽器開不會出現， 這是正常的，不是壞掉。

之後換了網址（例如換主機、改 repo 名稱），要回 LIFF 設定把 Endpoint URL 一起改掉，否則按鈕會開到舊網址。
方式 A · 直接貼網址零準備
  1. 複製你的名片網址。
  2. 在任何聊天室直接貼上送出。
  3. LINE 會自動抓取你的名片圖做成預覽卡，對方點了就開啟網站。
最省事，但預覽卡的大小和樣式由 LINE 決定，比不上方式 C 的大圖。
如果預覽卡沒顯示圖片，多半是 LINE 還沒抓到那張圖，過幾分鐘再試一次。
方式 B · QR code面對面
  1. 用 Chrome 開啟你的名片網址。
  2. 點網址列右側的分享圖示 → 建立 QR 圖碼 → 下載。
    不用另外找產生器，Chrome 內建。
  3. 把那張圖存進手機相簿，見面時給對方掃；或印在實體名片、貼紙、海報上。
適合面對面交換。對方掃完直接開啟網站，不用加好友、不用輸入任何東西。

第三步 · 加好友自動發名片 非必要

這一段非必要，大多數人不需要。做完第二步，你的名片就已經可以傳給任何人了。

這裡講的是另一件事：申請一個 LINE 官方帳號，讓別人加你好友時自動收到名片。 適合有在經營客戶名單、想累積好友數的人。

只是想把名片傳給別人的話，整段跳過，到這裡就完成了。
官方帳號設定步驟選配
  1. 開 manager.line.biz 登入，點進你的官方帳號。
  2. 右上角 設定 → 左側 回應設定：
    「自動回應訊息」設為 開啟、「Webhook」設為 關閉。
    自動回應沒開，歡迎訊息不會發出去。
  3. 回到 主頁 → 左側 圖文訊息 → 建立。
  4. 標題填 電子名片（只給自己辨識，好友看不到）。
  5. 按「選擇版型」→ 挑正方形、只有一整格的那個。
  6. 按「上傳背景圖片」→ 選 ZIP 裡的 card.png。
  7. 下方「動作」→ 類型選 連結 → 網址填第一步拿到的網址 → 儲存。
    這裡不要填 liff.line.me 開頭的網址，會跳授權畫面嚇到剛加好友的人。
  8. 左側 加入好友的歡迎訊息 → 編輯 → 把罐頭文字改成你的招呼 → 按 ＋ 新增 → 選 圖文訊息 → 選剛建好的「電子名片」→ 儲存。
  9. （建議）左側 自動回應訊息 → 建立 → 關鍵字填 名片 → 內容選同一則圖文訊息。這樣老朋友打「名片」也拿得到。
測試：歡迎訊息只對新加入的好友觸發，自己開對話測不到。 主頁 →「增加好友人數」→ 建立行動條碼，找個朋友掃碼加好友試試。

注意：圖文訊息存檔後不能換圖，要改得重新建一則再回歡迎訊息換掉。
資料只留在你自己的瀏覽器裡，不會上傳到任何伺服器。
