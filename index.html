LINE 電子名片產生器

填表單 → 下載 → 拖曳上線。不用寫任何程式碼。

右邊顯示的是範例。表單已經先填好一組假資料，讓你看得到效果—— 直接把每一格改成你自己的就好，預覽會即時跟著變。

1 · 基本資料

會顯示在名片圖和網站最上方。

2 · 形象照

會自動裁成直幅 3:4 並壓縮。建議用正面、背景單純的照片。

點這裡選照片 或把檔案拖進來 · JPG / PNG

框式：米白底 + 照片放在圓角框裡。適合去背或大頭照。
滿版：照片鋪滿整張，文字壓在下方漸層上。適合半身照、環境照。滿版會自動改用直式比例 2:3。

滿版提醒：照片下半部會被漸層蓋住放文字，請挑人物位於畫面偏上的照片。 人站太低的話臉會被文字壓到——先拉「裁切位置」滑桿往左試試，還是不行就換一張。
裁切位置 30%

往左＝保留較多頭頂，往右＝保留較多肩膀。調到臉在畫面中上方最好看。

3 · 自我介紹

空一行就會分段。建議 100～200 字。

4 · 連結

留空的不會出現。

5 · 聯絡方式

兩種都會寫進「存聯絡人」檔案，差別只在網頁上看不看得到。

網站是公開的。選「直接顯示」等於把號碼貼在網路上，垃圾訊息會變多。選「不顯示」的話，對方要按「存聯絡人」才拿得到。

6 · LIFF ID

先留空沒關係。網站上線後再回來填，重新下載一次即可。

填了之後，在 LINE 裡開啟時會多出「分享名片給好友」按鈕。沒填的話網站其他功能完全正常。

第一步 · 讓網站上線

  1. 解壓縮剛下載的 ZIP，會得到一個資料夾。
  2. 先註冊並登入 Netlify：用電腦的一般瀏覽器開 app.netlify.com， 按 Sign up，用 Google 或 GitHub 一鍵登入，免費。
    這步一定要在拖檔案之前做。沒登入就拖的話， 站台會被擋在登入牆後面，別人打開會看到錯誤，連你自己在 LINE 裡也開不了。
  3. 登入狀態下開 app.netlify.com/drop， 把整個資料夾拖進畫面中央的虛線框。
    是拖資料夾，不是拖裡面的單一檔案。
  4. 幾秒後會出現網址，像 https://melodic-tapioca-1a2b3c.netlify.app。
  5. （建議）進站台 → Site configuration → Change site name， 改成好記的名字，例如 你的名字-card。
  6. 用手機打開網址，確認照片、文字、連結都正常。把網址記下來，後面會一直用到。
怎麼確認真的公開了：用手機的無痕視窗（或請朋友）打開那個網址。 如果跳出 Netlify 的登入畫面，就是沒登入就拖了——登入後重拖一次即可。

往後要改內容：回到這一頁改好、重新下載，再拖一次到同一個站台。你填的資料存在瀏覽器裡，不會不見。

第二步 · 加好友自動收到名片

別人加你的 LINE 官方帳號，就自動收到名片圖，點了開你的網站。需要先有 LINE 官方帳號。

  1. 開 manager.line.biz 登入，點進你的官方帳號。
  2. 右上角 設定 → 左側 回應設定：
    「自動回應訊息」設為 開啟、「Webhook」設為 關閉。
    自動回應沒開，歡迎訊息不會發出去。
  3. 回到 主頁 → 左側 圖文訊息 → 建立。
  4. 標題填 電子名片（只給自己辨識，好友看不到）。
  5. 按「選擇版型」→ 挑正方形、只有一整格的那個。
  6. 按「上傳背景圖片」→ 選 ZIP 裡的 card.png。
  7. 下方「動作」→ 類型選 連結 → 網址填第一步拿到的網址 → 儲存。
    這裡不要填 liff.line.me 開頭的網址，會跳授權畫面嚇到剛加好友的人。
  8. 左側 加入好友的歡迎訊息 → 編輯 → 把罐頭文字改成你的招呼 → 按 ＋ 新增 → 選 圖文訊息 → 選剛建好的「電子名片」→ 儲存。
  9. （建議）左側 自動回應訊息 → 建立 → 關鍵字填 名片 → 內容選同一則圖文訊息。這樣老朋友打「名片」也拿得到。
測試：歡迎訊息只對新加入的好友觸發，自己開對話測不到。 主頁 →「增加好友人數」→ 建立行動條碼，找個朋友掃碼加好友試試。

注意：圖文訊息存檔後不能換圖，要改得重新建一則再回歡迎訊息換掉。

第三步 · 分享按鈕（選配）

裝了之後，你在任何聊天室開自己的名片，底下會多一顆「分享名片給好友」，按下去可以直接把名片傳給選定的人。不做也完全能用。

  1. 開 developers.line.biz/console， 用同一組 LINE 帳號登入。
  2. 點進你的 Provider（不是 Channel）→ Create a new channel → 選 LINE Login。
    一定要是 LINE Login，LIFF 不能建在 Messaging API channel 上。
    這不會多生一個官方帳號，兩種 channel 可以並存。
  3. 填寫：Channel name 建議用你的名字 + 電子名片（會顯示在授權畫面上）、 App types 勾 Web app、Email 填你的信箱 → 建立。
  4. 進入剛建好的 channel → 上排 LIFF 頁籤 → Add。
  5. 填寫：
    ・LIFF app name：電子名片
    ・Size：Full
    ・Endpoint URL：第一步拿到的網址（結尾的斜線要留）
    ・Scopes：勾 profile 和 chat_message.write
    chat_message.write 沒勾，分享按鈕按下去會失敗。
    ・Bot link feature：Off
  6. 建好後在 LIFF 頁籤點 shareTargetPicker，跳出的 「Agreement Regarding Use of Information」按同意。
  7. 複製 LIFF ID（長得像 2011841020-xONie09p）。
  8. 回到本頁第 6 格貼上 → 重新按「下載名片包」→ 重新拖到 Netlify 覆蓋。
  9. 用手機的 LINE 開 https://liff.line.me/你的LIFF ID， 第一次會跳授權畫面，按允許。分享按鈕就會出現。
分享按鈕只在 LINE 內建瀏覽器才看得到，用電腦或手機的一般瀏覽器開是不會出現的， 這是正常的，不是壞掉。
資料只留在你自己的瀏覽器裡，不會上傳到任何伺服器。
